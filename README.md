# Wispify Agent

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

> 🚧 **Under construction — building in public.** This is PR1 of a planned
> 13-PR rollout extracting a production WhatsApp AI agent into a public,
> single-tenant open-source starter. Expect missing features until the
> series lands; nothing here is production-ready yet.

Wispify Agent is a single-tenant WhatsApp AI assistant starter kit. It
connects Meta's WhatsApp Cloud API to Google Gemini for AI-driven replies,
with optional Google Calendar appointment booking and Stripe checkout, all
configured through a guided setup screen in an admin panel — no manual
`.env` surgery required for the integrations themselves.

## Status

This repository is being built incrementally, PR by PR, from a proven
private codebase. A full setup guide, architecture overview, and feature
list will land with the final PR in this series.
